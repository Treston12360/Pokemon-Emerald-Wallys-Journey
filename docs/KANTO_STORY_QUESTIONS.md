# Project ARIA — story questions

Questions about the Kanto story go **here**, not into a chat. One of the people working on the game does not
want the story spoiled, and the person who writes the story answers in this file (edit it on GitHub or have
your AI write the answer in).

How to use it:
- AI sessions: add a question under "Open" with the date, the task it blocks (from `docs/KANTO_TASKS.md`) and
  enough detail to answer without a chat. Push it. Carry on with work that does not depend on the answer.
- When it is answered, move it to "Answered", and copy the decision into `docs/KANTO_PROJECT_ARIA.md`.
